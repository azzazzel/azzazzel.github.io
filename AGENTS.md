# Agent guidance

## Project

This is Milen Dyankov's personal website, built with Nuxt 4, Nuxt Content, and Nuxt UI. Application code is in `app/`, content is in `content/`, and static assets are in `public/`. See `README.md` and `nuxt.config.ts` for more context.

## Development

- Use `pnpm`, not `npm` or `yarn`, to install dependencies and run scripts.
- A development server is usually already running. Do not start another instance.
- Use `pnpm build` for a production build and `pnpm generate` to generate the static site and redirects.
